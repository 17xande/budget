The automatic FNB fetch is not set up on this server. It needs FNB_USERNAME, the password in a file named by FNB_PASSWORD_FILE (a docker secret), and — if your login has several profiles — FNB_PROFILE. See the README. Until then, import downloads by hand.

{{else}}

Every day at the configured time the server logs in to FNB online banking with a headless browser, downloads the last 60 days of each cheque and credit-card account, and imports anything new — overlapping days are recognised and skipped. It tries once a day and never retries a failure on its own: repeated failed logins can lock a bank profile.
